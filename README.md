# 欧哟几 · 敦煌奇游记

安卓 4.3.0《旅伴有灵》。六岁的欧哟几跟着鹿铃走过河西走廊。沿途有六枚风铃、六段纹印旋律，还有 19 处能停下来观察和动手探索的景点。游戏用 Godot 4.7.2 制作，横屏、全中文，可离线游玩。

## 在安卓手机上玩

1. 将 [4.3.0 安卓安装包](builds/ouyoji-4.3.0-android.apk) 传到手机。已安装本工程交付的 4.0、4.1 或 4.2 时，直接打开新包覆盖升级即可继承行囊。
2. 在手机的“文件”应用里打开 APK。若系统询问，允许这个文件应用安装该安装包，然后完成安装。
3. 点开“欧哟几”，横屏游玩。不需要安装 Godot，也不需要启动电脑服务。

支持 Android 7.0 / API 24 及以上的 ARM64、ARMv7 设备，使用 OpenGL ES 3 Compatibility 渲染；不提供 x86 版本。包内含插画、中文字体、配乐和朗读。APK 采用本地调试签名，供直接安装体验。没有广告、账号、内购或网络请求。

## 和旅伴玩

从首页进入 **小营地 → 和旅伴玩**。点右侧的小物，让欧哟几和鹿铃打招呼、望远、思考、听铃、惊喜、庆祝、写生或休息。点 **猜猜动作**，两位朋友会演给你看。点对应的小物来猜，没看清可以再看一遍。直接点欧哟几会和他打招呼，点鹿铃可以听铃。

六站画卷上，摇杆和点地行走都会带动身体骨骼与衣饰，沙地、草地和石路上会留下不同的脚印。迎接、观察和拿到风铃时能看到旅伴的近景表情。行囊里的 **声音和画面 → 减少动态** 会把动作化作清楚的关键姿势，同样可以猜动作。

## 跟欧哟几逛景点

首页或河西地图点 **四时山河**，选一个城市，再点景点画卷。第一次打开会看到敦煌，也可以直接去其他五站。跟随风铃主线时，右上方的 **逛景点** 会打开脚下这一站。

| 旅途站点 | 可以停下来探索的景点 |
| --- | --- |
| 武威 | 雷台汉墓、武威文庙、天梯山石窟 |
| 张掖 | 张掖七彩丹霞、马蹄寺石窟、张掖大佛寺 |
| 酒泉 | 西汉酒泉胜迹、酒泉钟鼓楼、金塔沙漠胡杨林 |
| 嘉峪关 | 嘉峪关关城、悬壁长城、长城第一墩 |
| 瓜州 | 榆林窟、锁阳城遗址、双塔水库 |
| 敦煌 | 鸣沙山月牙泉、莫高窟、敦煌雅丹国家地质公园、玉门关遗址 |

- **在画里找东西。** 每处有三个标记，点开就能动手。沿月牙泉的弯岸描线，在莫高窟的写生纸上找共用耳朵的三只兔子，或在雅丹数风蚀丘的横纹。57 项观察有描线、配对、转动、复奏、揭画和排序六类操作。点 **观景镜** 可以用一根手指拖着放大镜看实景细部。
- **站在原地看四季和一天。** 点 **换季** 或 **换时** 可以直接选春夏秋冬、清晨、白天、黄昏或黑夜。点 **时光流转** 会每 18 秒换一次时辰，过了黑夜便翻到下一季。读信、做观察、翻写生页或切到后台时会暂停，回到原处接着走。写生页为每个景点留了 16 格，点 **收进写生页** 留下眼前的小画。
- **读鹿铃的来信。** 每处有一封采风信。收好信中指定的两幅时景，再完成一处指定观察，就能在景点画卷上盖一枚朱色采风印。来信里的按钮可直接带孩子去看对应画面。重玩已做过的观察不消耗收藏。
- **听当地的声音。** 泉边有水声，风过树林时有叶响，旷野里有轻沙和风。时辰、季节与环境共同决定晨鸟和夏虫是否加入。每处的景点故事标有资料提供机构。[逐处资料与取材说明](docs/landmark-sources.md)

## 继续风铃旅程

- 点“和欧哟几出发”。点地面或用左下摇杆移动。点风景标记，欧哟几会沿脚印走过去；右下的圆盘可以直接聊天、帮朋友、收风铃或寻纹。
- 每站听完故事，选一个自己的回答，发现两处风景，再帮朋友做一件事。每到一个景点完成第一项观察，也会为该站记一处风景。六枚风铃按旅途顺序收集，每站的寻纹机关可随时挑战。
- 武威和酒泉可以逐个点足迹或用手指连起来，张掖和嘉峪关转镜引光，瓜州和敦煌要移动画带拼出图案。解开机关会得到该站纹印，同时记下一处风景及相关知识卡。卡住可以点“看提示”或“退一步”。
- 在首页或地图点“纹印谱”，选一枚已取得的纹印听它的旋律。六枚集齐可点“听六纹合奏”。八段原创场景配乐各有安静和行进两层，角色走动、解谜时伴奏会加入，朋友说话时音乐会变轻。[合奏试听](tools/score/seal-song-preview.mp3)
- 地图可以随时回访六站。十一种小游戏包括装行囊、水渠、记忆配对、过关城、复奏、拼图、涂色、历史排序、织带、天平和星图。
- “送问候”接取并送达三份小礼物，解锁营地摆设。在营地摆东西、写八拍小曲，还可以保存一张明信片。
- “发现图鉴”收录 31 张知识卡、12 段历史和旅途手记。故事与角色是原创想象，历史资料单独标明出处。
- “行囊”可以设置声音、音乐音量、朗读和减少动态。系统返回键先收起对话，印谱会记住来时的站点。

没有倒计时或惩罚，适合成人陪伴儿童一次探索一两站。

## 保存和搬家

进度保存在当前设备的应用私有目录，自动写入并保留备份。到“行囊 → 保存与搬家 → 导出行囊文件”选择文件夹，得到中文命名的 JSON；在另一台设备选择“导入行囊文件”即可。也可复制/粘贴行囊文字。支持原版 v1/v2 行囊。

导入会合并收藏与主线。景点发现、写生小画会去重合并，同一份画作和已自定义营地以导入内容为准。损坏文件不会静默覆盖有效存档。若存储空间或文件保护导致保存失败，顶部会持续提示，并允许重试或导出当前内存进度。

卸载应用会移除本机进度，请先导出行囊。自行在另一台电脑生成的调试密钥通常不同，不能直接覆盖安装这个 APK；如需更换签名，请先备份行囊，重新安装后再导入。

## 在电脑上打开工程

安装官方 **Godot 4.7.2 标准版**，导入本目录的 `project.godot`，等待首次资源导入后按 **F5** 运行工程。兼容渲染器已配置。鼠标可以代替触摸，方向键可以行走。工程不依赖上级 Web 项目、npm 或运行中的后端。

下载 [4.3.0 完整源码](builds/ouyoji-godot-source-4.3.0.zip)，解压后同样导入 `project.godot`。压缩包内附两位旅伴的骨架、可动分层画稿、四季画稿、57 项观察、场景、脚本、音频、中文字体、测试与乐谱制作文件。开发工具链在另一台电脑上单独安装。

开发主机的自包含脚本适用于 **macOS Apple Silicon**，在本目录执行：

```sh
tools/setup-toolchain.sh
tools/godot.sh --editor --path .
tools/check.sh
tools/export-android.sh
```

在 Windows/Linux 上可以直接用 Godot 编辑器打开与运行。需要重新导出 Android 时，安装匹配的导出模板、JDK 17、Android SDK Build-Tools 36.0.0 / Platform 36，在编辑器设置里填写本机路径与调试密钥，再导出 `Android Debug`。具体版本、来源和参数见 [工具链说明](docs/toolchain.md)。
