# 旅伴可动画稿

欧哟几与鹿铃沿用本游戏原有的六岁男孩、旅行衣饰及敦煌小鹿设定。2026 年 11 月使用内置 ImageGen 辅助绘制角色和营地织毯。分层、画面裁切、二维关节、蒙皮、表情时序与动作表现由本项目完成。APK 内只需编译好的本地资源。

- 男孩的头部图集保存九张同机位面孔，包括自然神情和八种动作。手形和眼睑图集配合骨骼决定动作。[欧哟几画稿](boy/)
- 鹿铃的近远两耳与铃穗可以独立旋转，四肢用连续的画稿和屈腿部件完成行走及歇息。[鹿铃画稿](deer/README.md)
- `camp_rug.webp` 是专为旅伴近景绘制的透明织毯画稿。边缘保留穗线，黛青与茜红纹样在营地的沙地上给两位旅伴留出落脚的位置。
