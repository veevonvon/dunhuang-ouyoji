# 《寻纹听铃》插画资源

2026-11-19 使用本会话内置 ImageGen 为本游戏绘制。封面以工程已有的 `assets/images/boy.png`、`deer.png` 和 `map.jpg` 为角色与用色参考。两组贴图各自使用一张 3 × 2 的透明原画。用 Pillow 从原画按格裁切，保留原透明通道，并等比缩放、居中和编码为 WebP。

## 开场绘卷

`opening.webp` 为 1664 × 936 的横屏满幅封面。主要绘制提示为：六岁黑发男孩着红围巾、青绿绣花背心，佩褐色挎包，在洞口回望戴铃的金纹白鹿。夕照下的祁连雪山、丹霞和蜿蜒驼道向远处退去。细线勾勒人物，以石青、石绿、朱砂和薄金层染绢面。角色落在左侧，右侧岩壁留出连续的深青阴影供界面排字。无字。

## 小游戏里的画绢与物件

十一项小游戏共用 `props/silk-ground.webp`。绘制提示为淡杏色的空白绢本，保留交错丝纹，左下以极淡赭金描远山和芦苇，右下以石绿晕染沙丘。翻牌使用专绘的 `props/card-back.webp`，以孔雀青绢、飞天飘带、莲花和双道金线组成牌背。

`props/` 中的九件旅途物件来自一张独立透明原画。绘制提示为三行三列的工笔重彩小物，分别描绘带提绳的青釉水壶、麦穗粮袋、红绿织绸、系绳书卷、拼皮球、现代手机、葡萄、斜抱琵琶和背鞍毯的小骆驼，保持缩小时的外形差异。各物件裁成 288 × 288。另一张原画描绘绿叶、水滴、莲花、太阳、星星和绿洲树苗，各裁成 256 × 256，供音乐、水渠、织带和星图使用。原画均由同一内置 ImageGen 工作流创作。
