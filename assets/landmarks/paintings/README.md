## 画幅与位置校验

76 个成品均为 **1600 × 900 像素、RGB WebP**，解码后的像素摘要各异，WebP 文件合计 25,270,120 字节（24.10 MiB）。先以胡杨、月牙泉、莫高窟试绘四季拼图，确认机位与植物状态。正式春、秋、冬稿各以对应夏景作为单幅编辑底图，原始输出为 1672 × 941 像素，经轻微位置配准与等比缩放，以 WebP 质量 85 编码。胡杨的叶量、月牙泉的干苇和酒泉冬季的活泉水面均在画布上完成。

在成品尺寸下，将 57 张季节图逐一和各自夏景对照。用 SIFT 识别土层、瓦檐、树干、岸石等静态细节，为需要微调的画面校正平移、旋转或等比缩放。再次解码正式 WebP，每组检测到 92 至 649 个位置一致的特征点。留出约五分之一的匹配点作交叉检查，剔除超过 25 像素的歧义匹配后，各组位移中位数为 0.39 至 1.75 像素。

逐项核对游戏数据里每处的三个观察点，三季共 171 组。170 组从附近固定纹理估算局部位移。冬季月牙泉的沙脊一带纹理较少，改用三个大小的边缘窗口比对，测得 0.64 至 0.98 像素。所有观察点中最大的局部位移估值为 2.84 像素，出现在冬季莫高窟的窟壁观察点。下表的两列误差均按 1600 × 900 的成品像素计。
