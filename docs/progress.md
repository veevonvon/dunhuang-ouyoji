# 实施与审查记录

2026-11-19，计划见 `implementation-plan.md`。

## 决策

- 用户要求自主重构、不询问需求。采用独立目录，保留全部旧版与存档，不初始化 Git、不提交、不发布。
- 使用原生 Godot 4.7.2、GDScript、Compatibility。复用原创插画，角色深度缩放、影子、镜头跟随和粒子形成 2.5D；没有改成完整 3D 模型制作流程。
- 工具链、领域与素材、小游戏分别按文件所有权并行；主协调实现世界/UI/音频并整合。界面模块通过 Library/Journey 和 MiniGameView 信号连接，不依赖原网页运行时。
- 无付费 API、生产服务或额外运行插件。工具链只装到本项目 `.toolchain/`。

## 完成的工作

1. 官方引擎、模板、JDK17、SDK36 和本地调试签名；固定下载校验值、独立编辑器数据路径与可复现导出命令。
2. 六章、十八处发现、三十一知识卡、十二历史段、十一玩法、三封问候、九件摆设；158 图音文件字节保持一致；中文字体及完整许可。
3. 全部十一玩法原生实现，实际胜利路径、错误动作、重复奖励、快速划线、多指、取消、离开等待中棋盘均有回归。
4. 首页、画卷地图、角色行走、镜头、世界交互、主线、图鉴、问候、营地、作曲、六风铃结局、离线音频、原生文件保存/导入。
5. 真实引擎截图检查；独立审查后的返回键、存档反馈与多指修复；源码与安装说明。最终 APK 的系统验收另见 `verification.md` 和 `toolchain.md`。

## 失败到修复的证据

- 最初集成测试因主场景尚不存在失败，随后实现后通过。
- 界面中文曾落到字体默认100细体；通过 TextServer 查询复现未选中轴，改用 OpenType 整数轴与500字重后检查通过。
- 持续按键在模态对话背后移动角色，回归失败后统一暂停世界与角色物理处理，通过。
- 音乐交叉淡入覆盖朗读压低音量，音频测试失败；改用独立淡入比例、按实时朗读状态混音后通过。
- 独立审查复现系统 Back 直接退出、保存失败提示被领奖覆盖、摇杆次指残留目标。边界测试先8项失败，修复为14项通过。
- 仅发送 Android PAUSED 时小游戏手势/乐句未取消，追加2项失败测试；同时处理 PAUSED 后16项全通过。
- 进程立即结束时 AudioServer 尚未回收 MP3 播放引用；停止并释放全部播放器，在测试清理中等待混音线程后，无退出泄漏警告。
