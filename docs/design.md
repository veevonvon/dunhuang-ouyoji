# 欧哟几 · Godot 安卓重构设计

日期：2026-11-19。用户希望彻底摆脱网页观感和不稳固的按钮布局，获得能在安卓手机上安装游玩的游戏。原定自主实施、不问需求问题的授权继续有效。

## 实施选择

采用 Godot 4.7.2 标准版 + GDScript + Compatibility；横屏 1280×720 逻辑基准，canvas_items + expand 适配宽屏，安全区约束 HUD。原生 Node2D / CharacterBody2D / Camera2D 构成世界，Control / Container / Theme 构成游戏 UI。原版资源和内容迁入独立工程，不调用 JavaScript 或加载网页。完整 3D 重建会损失现有矿彩插画并扩大制作范围；本轮选择有景深、镜头跟随、角色行走与前景粒子的 2.5D。

## 产品

- 欧哟几为六岁小男孩，鹿铃同行；全中文、温柔引导，没有倒计时、伤害、惩罚或付费功能。
- 保留武威、张掖、酒泉、嘉峪关、瓜州、敦煌六章，18处发现、31张知识卡、12段历史、六枚风铃结局。
- 保留11种玩法：装行囊、水渠、记忆配对、过关城、乐句复奏、壁画拼图、莲花涂色、时光排序、织带、天平、星图。使用原生按钮/触摸输入，支持点按；涉及移动的玩法增加拖放或划线。
- 保留三封跨站问候、营地九件摆设与八拍作曲。六件摆设初始开放，回信解锁三件。
- 主界面以画面和人物为主。场景上方仅显示目的地和风铃，左下移动区、右下上下文操作。地图为旅行路线，知识与小游戏作为行囊中的收藏。
- 按钮至少64逻辑像素高；常用字24px左右，不靠压缩字宽；长文字由容器换行。按下时有配色、阴影反馈，发现和奖励有提示音，减少动态设置可关闭持续动效。
- 原创插画、八段配乐、中文配音沿用并打包离线。新的程序图形只绘制纹样、图标和粒子，不改写原画。

## 存档和技术

安卓使用 user:// 原子写入并保留备份。沿用 v2 数据结构，通过 JSON 导入/导出兼容原版，不自动访问浏览器存档。无效或损坏文件不得覆盖原存档，导入前完整校验。设置区支持声音、音乐、朗读、减少动态；返回键先关闭弹窗，再退出当前玩法，不清空进度。

字体采用具有再分发许可的简体中文字体并携带许可证。APK 不申请网络、相册、定位、麦克风等无关权限。常用手机 arm64 架构，另提供32位 arm 支持（引擎模板允许时）。本地调试签名，仅供安装游玩，不上传商店。

## 验收

Godot 工程可导入，无解析错误；六章和全部玩法通过真实规则测试；多尺寸 UI 文本不越界，触摸点击和取消可验证；桌面引擎实际渲染截图；可生成签名有效的 APK 并检查资源和架构。能使用安卓模拟器时进一步启动 APK 并读取运行日志；不可用时明确保留真机验收限制，绝不称未运行的验收已通过。
