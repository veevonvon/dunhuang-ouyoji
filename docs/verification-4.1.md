# 《寻纹听铃》4.1.0 游戏验收

2026-11-19，Godot 4.7.2，Compatibility 渲染器。验收覆盖桌面引擎、原生多点触摸事件和 Android 15 ARM64 模拟器。尚未在实体手机或六岁儿童中开展试玩。

## 游戏与行囊

运行 `tools/check.sh`，引擎导入通过，以下有计数的断言共 2,000 项，另有两套声音测试通过。各检查日志由脚本写到 `test-results/checks/`。

| 检查 | 通过数 | 覆盖内容 |
| --- | ---: | --- |
| 领域与存档 | 191 | 保存恢复、导入导出、风铃主线和营地 |
| 纹印保存 | 15 | 老行囊、导入合并、无效 ID、风景和知识随印一次入档、重玩 |
| 经典小游戏 | 491 | 十一种游戏、拖放或点按、触区大小和边界 |
| 六个新机关 | 213 | 两种操作路径、识图、提示、撤销、副手指、失焦取消与通关 |
| 移动与布局 | 1,020 | 三种比例下的控件可见性、按钮文字高度、字体、移动和画面边界 |
| 输入边界 | 19 | 触摸取消、弹窗焦点、系统返回、后台和写盘失败 |
| 完整主线 | 32 | 从武威到敦煌的旧风铃主线与结局 |

独立触摸复核另从含旧收藏的 v2 行囊开始，经印谱逐站解开全部六个机关，逐个重听，解锁整首合奏，再重复武威。重复游玩后仍是六枚纹印、六个对应的风景，原有收藏保留。关掉印谱会停止合奏。

## 画面与声音

原生 OpenGL 生成 28 张主场景截图，含 1280×720、1560×720、1024×768。另逐一渲染了十一个经典小游戏和六个寻纹机关。复核发现的平板底部露底和模态确认键穿透均有回归检查。重新生成主场景截图可运行下列命令。

```sh
tools/godot.sh --path . --script tests/render_scenes.gd
tools/godot.sh --path . --script tests/test_trails.gd -- --capture-trails
```

素材检查覆盖 158 份原有图音哈希、30 张新增插画、2 张机关画带、28 份 Vorbis 音频、两套中文字体与许可。音乐检查逐轨解码 24 kHz 双声道文件，验证八组分轨各自等长、循环交界、六种独有音型、立体声与峰值余量。合奏为 633,600 帧、26.40 秒，峰值 −7.82 dBFS。

`test_audio.gd` 与 `test_score.gd` 涵盖实际引擎播放、走动伴奏电平、语音压低背景乐、场景切换、静音和后台。印谱串联测试还核对合奏自然结束后可再次播放。在首页选“下次再见”时，游戏先停止音轨，再给混音线程回收资源；`test_rest.gd` 经实际告别按钮退出，检查日志中无播放引用残留。[配乐与重建步骤](../tools/score/README.md)

## 安卓安装与复现

安卓安装包为本机调试签名，包名沿用 `org.ouyoji.dunhuang`，版本代码 40100。已在横屏 2340×1080 的 Android 15 ARM64 模拟器上从 4.0.0 覆盖升级，安装后首次启动前，旧版私有存档逐字节一致。普通启动后经实际触屏完成武威，纹印和关联风景入档，游戏原有收藏保留。其它五站的交互覆盖来自桌面 Godot 触摸事件测试。[安卓截图、签名、校验值与复测记录](android-4.1.md)

独立源码交付使用 `python3 tools/package-source.py`。压缩包顶层为 `ouyoji-godot-4.1.0/`，包含重建所需的脚本、音画、内容、许可与测试。复查时解压到全新目录，以相同版本的 Godot 导入 `project.godot`，再从解压目录运行素材核对、印谱串联、声音和告别测试。APK 和源码包旁均提供 SHA-256 文件。
