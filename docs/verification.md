## Android 系统验证

官方 Android15 / API35 ARM64 模拟器，Pixel5配置；安装实际导出的 APK。已实测首页启动、进入武威、中文故事、小游戏点按/拖放完成并保存印章。系统 DocumentsUI 导出 JSON 到 Download，再导入同一份文件，content URI 授权与结果均正常，无外部存储权限请求。

初次系统 Back 实测发现自动退出，与桌面调用 `go_back()` 的结果不同；增加 SceneTree.quit_on_go_back=false 后重新导出安装。最终包单次 Back 在弹窗仅收起弹窗、在小游戏仅返回武威，进程保持运行；Home 后回前台是同一进程，强停后冷启动仍保留已获得的印章。最终截图在 `test-results/android/home.png`、`world.png`、`minigame.png`，更多系统记录见 `toolchain.md`。

最终 APK 通过 v2/v3 签名、16KB 原生库对齐、ARM64/ARMv7 双架构、零 uses-permission、中文字体、完整内容和许可文件检查。`tools/export-verify.py` 另检查 APK 不含网页、JS、工具链、测试和密钥；工作目录 SHA-256 清单复核通过。

## 验收边界

没有连接实体安卓手机，没有完成不同厂商的系统手势、全面屏形态、低端机持续帧率与耗电矩阵，也未模拟真实断电。Android15模拟器的验证不能代表所有实体设备。APK 是本地调试签名；没有执行商店发布或生产签名流程。

地图与场景为敦煌矿彩风格的艺术概括，采用插画层、角色深度与镜头的2.5D表现；不是完整3D场景。历史知识与来源独立于虚构主线保留。
